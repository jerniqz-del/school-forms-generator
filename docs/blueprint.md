# **App Name**: Irosin II District Web App

## Core Features:

- Dashboard Statistics: Display key statistics such as the number of schools, teaching personnel, non-teaching personnel, and learners in an organized manner.
- Navigation Buttons: Include buttons for News, Announcements, Issuances, Schools, and Tools, each redirecting to dedicated pages.
- News Section: A page displaying news articles and updates related to the school district.
- Announcements Section: A page dedicated to displaying important announcements for the district.
- Issuances Repository: A section to store and display official issuances from the district.
- Schools Directory: A directory listing all schools within the Irosin II district.
- AI-Powered FAQ: An FAQ page populated using a generative AI tool, using district documentation for reference. End users can find information related to the Irosin II district.
- Mock Datasets: Populate details with mock datasets

## Style Guidelines:

- Primary color: Blue (#468BFF) to convey trust and stability, reflecting the district's reliable nature.
- Background color: Light gray (#F0F4F8), providing a clean and professional backdrop that enhances readability.
- Accent color: Soft teal (#49E2D0) used for interactive elements like buttons and links to add a touch of modernity.
- Body and headline font: 'PT Sans', a humanist sans-serif that provides a modern look with warmth and personality.
- Use clear, simple icons for each section (News, Announcements, etc.) to enhance navigation.
- Employ a clean and responsive layout that adapts well to different screen sizes for accessibility on all devices.
- Subtle animations for page transitions and button hovers to improve user experience.
